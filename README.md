## Practical Work 2: GitHub và Labwork 1/1b

Repository này là fork của [repo lớp L2](https://github.com/phuongnghiem/Python-2026-L2).
Theo xác nhận của giảng viên ngày 11/10/2026, PW2 gồm thực hành GitHub
và nộp Labwork 1/1b. Labwork 1b là chương trình nền để phát triển PW3.

Chạy bằng Python 3 từ thư mục repository; hai bài dùng thư viện chuẩn:

```text
python labwork1.py
python labwork1b.py
```

- `labwork1.py`: 12 bài Python cơ bản. Câu 5 dùng danh sách màu tự chọn,
  được giảng viên cho phép; Red ở index 3 và Green không có trong danh sách.
- `labwork1b.py`: nhập sinh viên, môn học, điểm và xem các bảng kết quả.

[Dự án các bài tiếp theo và báo cáo](https://github.com/NhatHieu2808/Python-2026-L1)
được lưu trong repository L1 hiện có.
